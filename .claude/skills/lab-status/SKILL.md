# lab-status

저장소 루트의 `AGENTS.md`를 읽고, **"A. 진행 상황 브리핑"** 절차와 출력 형식을 그대로 수행한다.
같은 파일의 "반드시 지킬 것"도 함께 따른다. 브리핑은 읽기 전용이고, 풀이와 힌트는 주지 않는다.

절차는 이 파일이 아니라 `AGENTS.md`에서만 관리한다. 다른 에이전트도 같은 절차를 쓰게 하기 위해서다.
