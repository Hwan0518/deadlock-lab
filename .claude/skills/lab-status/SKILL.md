# lab-status — 실험 진행 상황 브리핑

세션을 새로 시작한 사람(다른 PC 포함)이 이 한 번의 호출로 맥락을 되찾게 하는 것이 목적이다.
**상태를 기억이나 이 파일에서 가져오지 말고, 매번 저장소에서 읽어서 계산한다.** 이 파일에는 절차만 있다.

## 지켜야 할 것

- **읽기만 한다.** 파일 수정, 커밋, 브랜치 전환, push, PR 코멘트를 하지 않는다. (`git fetch`는 허용)
- **풀이를 주지 않는다.** "사람이 할 일"은 문제지의 요구사항을 옮겨 적는 수준까지만 쓴다. 구현 방법, 힌트, 코드 리뷰는 사람이 요청할 때만 한다.
- 작성 중인 코드가 컴파일되지 않아도 고치지 않는다. 사실만 보고한다. (예: "`StockService.java` 컴파일 실패 — 1-1 진행 중")
- 판단마다 근거(파일 경로, 커밋, PR 번호)를 붙인다. 근거가 없으면 "확인 못 함"이라고 쓴다.

## 절차

1. **원격과 맞추기**
   - `git fetch --all --prune`
   - 현재 브랜치, 원격 대비 앞섬/뒤처짐, 커밋 안 된 변경을 확인한다: `git status -sb`
2. **목표와 규칙 읽기** — `README.md`의 원칙, 문제 현황, 역할 분담, 시리즈 구성, 진행 방식.
3. **진행 중인 문제 찾기** — README `문제 현황` 표에서 상태가 `진행 중`인 행을 찾는다. 그 행의 문제지와 브랜치를 기준으로 삼는다.
   - 진행 중인 문제가 없으면 마지막으로 `완료`된 문제를 알려 주고, 다음 문제 출제가 AI 세션의 할 일이라고 보고한다.
4. **문제지 읽기** — 요구사항의 하위 단계(`### N-1.`, `### N-2.` …), 제약, 제출할 것을 파악한다.
5. **진척 측정** — 문제 브랜치 기준으로 아래를 확인한다. (현재 브랜치가 문제 브랜치가 아니면 `git show origin/<브랜치>:<경로>`로 읽는다)
   - 브랜치에만 있는 커밋: `git log --oneline main..origin/<브랜치>`
   - 브랜치에서 바뀐 파일: `git diff --stat main...origin/<브랜치>`
   - `answers/NN-*.md`에서 비어 있는 칸과 채워진 칸
   - 열린 PR과 리뷰 상태: `gh pr list --head <브랜치> --state all --json number,state,title,reviewDecision,url` (gh가 없거나 실패하면 생략하고 그렇다고 쓴다)
   - 현재 브랜치가 문제 브랜치이면 컴파일만 확인한다: `./gradlew compileJava compileTestJava -q` (Docker 불필요. 실패하면 첫 에러 몇 줄만 인용)
   - 하위 단계마다 `완료` / `진행 중` / `미착수`로 판정한다. 판정 기준:
     - 코드 단계: 해당 코드가 있고 컴파일되며, 그 단계를 겨냥한 테스트가 있으면 `완료`
     - 측정·관찰 단계: `answers/`의 해당 칸이 채워져 있으면 `완료`
     - 그 외 흔적만 있으면 `진행 중`, 흔적이 없으면 `미착수`

## 출력 형식

아래 순서와 제목을 그대로 쓴다. 전체 30줄 안팎으로 짧게 쓴다.

```
## 전체 목표
(README 기준 2~3줄: 시리즈의 목적, 원칙, 지금 문제가 시리즈의 어느 편에 속하는지)

## 현재 진행 상황
- 문제: <번호와 제목> — 문제지 경로 / 브랜치 / PR(있으면 번호와 상태)
- 로컬 상태: 현재 브랜치, 원격 대비 앞섬·뒤처짐, 커밋 안 된 변경
| 단계 | 상태 | 근거 |
|---|---|---|
| N-1 ... | 완료/진행 중/미착수 | 파일·커밋 |

## 내가 할 일 (사람)
1. 지금 바로 할 일 — 문제지의 해당 요구사항을 그대로 요약 (방법·힌트 없음)
2. 그다음 할 일
- 필요한 명령 (브랜치 이동, pull, 테스트 실행 등)

## AI 세션이 할 일
- 지금 단계에서 AI가 맡는 일 (예: 대기 / PR 리뷰 / 측정값 검증 / 다음 문제 출제)
- 하지 않는 일 한 줄 (README 역할 분담 기준)

## 이렇게 요청하면 됨
- 막혔을 때, 제출할 때 등 지금 단계에 맞는 요청 예시 1~2개
```
